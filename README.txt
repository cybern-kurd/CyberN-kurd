CYBERN KURD WEBSITE
====================

فایلەکان:
- index.html : پەڕەی سەرەکی
- style.css  : دیزاین
- script.js  : بابەتەکان و کارلێک
- logo.png   : لۆگۆی CyberN Kurd

بۆ زیادکردنی بابەت:

بۆ گۆڕینی لینکەکانی Instagram:
لە index.html ـدا href ـی Instagram بگۆڕە.

بۆ بڵاوکردنەوە:
ئەم فۆڵدەرە دەتوانیت لە GitHub Pages یان Cloudflare Pages بڵاو بکەیتەوە.
